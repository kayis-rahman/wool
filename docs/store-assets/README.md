# Wool store assets

Store-only assets. These are not used by the app targets.

- `icon-googleplay-512.png` (512x512, no alpha): Google Play store listing icon.
  Source: `selected-mint/icon-googleplay-512.png` from the Wool store-art brainstorm
  (L2 woolly sheep direction, final variant M2, mint colours).
- `logomark-1024x512.png` (1024x512): logomark for store/marketing surfaces.
  Source: `selected-mint/logomark-1024x512.png` from the same selection.

The in-app icon ships from `apple/Wool/Wool/Assets.xcassets/AppIcon.appiconset`.
